## 5. Suggested case-study video framework
Use the same 60–90 s structure for every case study so the series feels like one product:

1. **Hook (0–5 s):** client logo + one-line challenge ("How do you make 3D machinery feel simple?")
2. **The brief (5–15 s):** industry, audience, objective
3. **Our approach (15–40 s):** concept, format (live action / 2D / 3D / AI / drone), BTS clips
4. **The film (40–65 s):** hero shots and best moments from the final video
5. **Impact (65–80 s):** results, deliverables (e.g. "12 regional-language testimonials") and the client quote
6. **End card (80–90 s):** Orange Videos logo + "Videos That Tell Powerful Brand Stories" + orangevideos.in

**Per-project data to collect** (the website doesn't publish it, so ask each project lead):
client, industry, brief/challenge, format, shoot days/locations, languages, number of deliverables,
timeline, platforms, results/metrics, client quote, and BTS footage availability.

**Strongest first picks** (big brands, visual variety, existing testimonials): Hapag-Lloyd
(brand + drone), IDEX (3D product), Tata AIG (testimonial series), Schindler (documentary),
India Glycols (2D animation).

## 6. Logo / brand assets
The logo could **not** be downloaded: the research environment's network policy blocks
`orangevideos.in`. To add it:
1. Download the master logo files from the team's design drive. Don't use the website's
   compressed web images. Ideal set: SVG + transparent PNG in full-colour, white
   (reversed) and black versions, plus the icon/mark alone.
2. Put them in `orange-videos/brand/` and record the brand orange HEX value and the fonts here
   so motion-graphics templates stay consistent.
